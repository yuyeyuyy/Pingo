# Pingo

Pingo 是一款本地优先的 macOS 桌面学习工具。导入或创建自己的题库后，Pingo 可以按设定间隔提醒你答几道题。

- 用题库卡片管理基础题库和语言题库，支持选择、填写、填空和排序。
- 每个题库有错题本和收藏本。在学习提醒中可选抽题范围，或每隔几轮复习错题。
- 选择系统通知或独立弹窗，设置间隔、每轮题量、暂停和勿扰时段。
- 稍后提醒会保留本轮进度。设置、题库和已提交的答案保存在本机 SQLite 数据库中。

## 从源码运行

需要 Node.js 24.14 或更新的 24.x 版本。测试中的词库转换脚本另需 Python 3.9 或更新版本。

```sh
npm ci
npm run dev
```

在「题库」新建题库并选择模板，再从卡片导入 [基础示例](docs/example-question-bank.json)或[语言学习示例](docs/example-language-bank.json)。可以把文件拖到卡片上。然后从「设置 → 学习提醒」点击「立即学习」。关闭主窗口后应用继续在后台运行，从应用菜单或托盘选择「退出 Pingo」可结束运行。

在「设置 → 学习提醒」中先选择题库，再保存它的学习策略。「全部题库」为混合抽题保存独立策略。带答题的模式使用循序渐进时，按题库难度和题池进度练习，每轮约 40% 新题、30% 复习一次、30% 错题。导入窗口可以复制 Agent 转换提示词，让 Agent 先给词表中的单词分档，再按题型换算难度。具体规则见[渐进学习器设计](docs/LEARNING_ENGINE.md)。

在「设置 → 学习提醒 → 学习模式」选择「学习验证模式」可先阅读资料再答题，「练习模式」直接答题。「纯学习模式」每轮只看资料，支持导入只含 `materials` 的 JSON，也可以选循序渐进或随机抽取。循序渐进优先展示没看过的资料，同一轮每个词最多展示一次。[语言学习示例](docs/example-language-bank.json)

新建语言学习题库时可选择学习语言。英语题库里，学习资料的单词标题、单词选释义的题干单词和提交后揭晓的单词、释义选单词的选项都可以点击发音。录音来自 [Free Dictionary API](https://dictionaryapi.dev/)，录音不可用时会尝试本机的英语语音。

在「设置 → 英语发音」可选择本机英语语音、调节语速并试听。选择「本机语音优先」后，有可用的本机语音就直接播放。语音列表取决于当前系统已安装且可供应用使用的语音。

## 检查与打包

```sh
npm run typecheck
npm run lint
npm test
npm run build
npm run package:mac
```

打包命令在 `dist/Pingo-darwin-<arch>/Pingo.app` 生成本机架构的应用。更多说明见[架构文档](docs/ARCHITECTURE.md)和 [CET4 词库转换说明](docs/cet4-converter.md)。转换用的原始词库和生成数据由使用者在本机提供。
