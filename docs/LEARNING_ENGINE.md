# Pingo 渐进学习器设计

目标是让每次弹窗包含几道难度合适的题，并用之后还能否回忆起来衡量效果。学习器是一个可选抽题策略。现有设置继续决定什么时候弹窗、选哪个题库以及抽多少题。

## 研究依据

- **先作答，再看反馈。** 外语词对实验发现，学会之后继续做回忆测试改善了延迟回忆。Pingo 应在提交后展示答案，复习时再次要求作答。[Karpicke 与 Roediger，2008](https://doi.org/10.1126/science.1152408)
- **分散复习。** 实验发现，合适的练习间隔会随目标保留时间变化。一项二语词汇实验比较了递增、等距和递减间隔，延迟测试未发现三组有显著差异。首版可以从一组易解释的间隔开始，再用延迟回忆结果校准。[Cepeda 等，2008](https://laplab.ucsd.edu/articles/Cepeda%20et%20al%202008_psychsci.pdf) · [Kanayama 与 Kasahara，2017](https://www.jstage.jst.go.jp/article/arele/28/0/28_113/_article/-char/en)
- **按目标练习。** 一项小规模二语实验发现，练习回忆词形的组在产出型测试中表现更好。如果目标是会拼写或使用单词，应让同一个词有独立的填写或语境题。选择题提交后明确纠正答案，并展示来源可靠的干扰项释义。[Yanagisawa，2016](https://www.jstage.jst.go.jp/article/katejournal/30/0/30_11/_article/-char/en) · [Butler 与 Roediger，2008](https://pubmed.ncbi.nlm.nih.gov/18491500/)
- **小挑战用于探测。** 「85% 规则」主要研究二元分类任务下的训练难度。Pingo 采用少量挑战题来观察下一档的表现。本文的等级、升降档阈值和间隔都是产品初值。[Wilson 等，2019](https://www.nature.com/articles/s41467-019-12552-4)

## 导入和难度标注

导入提示词让 Agent 先给词表里的不同单词分档，再换算每道题的 `difficulty`，值为 1 至 5 的整数。词频、教材分级、课次和例句可用作参考。只有单词和释义时，Agent 按常见程度、使用范围和目标义项估档，并在报告中给出依据。

| 单词档位 | 分级依据                   | 例子       | 选择题难度 | 独立拼写难度 |
| -------- | -------------------------- | ---------- | ---------- | ------------ |
| 1        | 基础日常词汇，词义直观     | `apple`    | 1          | 2            |
| 2        | 常见生活、学习或工作词汇   | `borrow`   | 2          | 3            |
| 3        | 跨场景使用的较抽象通用词汇 | `reliable` | 3          | 4            |
| 4        | 正式、专业或较少见的词汇   | `mitigate` | 4          | 5            |

单词档位记录在转换报告中，导入文件保存换算后的题目难度。选择题沿用单词档位，独立拼写加 1 级。词汇填空按是否需要独立回忆词形来取等级，语法和句子题可按知识点和作答步骤直接估级。对同一词义的变体可附加可选的 `conceptKey`，例如 `apple:n:fruit`。Pingo 用它避免同轮先看选项再拼写同一词。两道题各自保存复习进度。

旧 JSON 可照常导入。没有标注时，Pingo 使用题型默认值，单词选释义 1，其他选择题 2，填写和填空 3，排序 4。题库中可以抽查和修改等级。

```json
{
  "kind": "short-answer",
  "languageType": "word-spelling",
  "prompt": "写出表示「苹果」的英文单词。",
  "acceptedAnswers": ["apple"],
  "difficulty": 2,
  "conceptKey": "apple:n:fruit"
}
```

## 学习器怎样出题

下面的轮次配额适用于练习模式。学习模式下，每个词每轮配一道题，同一题库中的不同题型和同名单词资料共用展示进度。先选从未展示过的词，新词不足时用到期题或较久未展示的词补足。

1. **确定题池。** 先沿用已选题库和完整题库、错题本、收藏本规则。完整题库模式在每第 N 个完成轮次指定错题池。错题本实际为空时，同一题库范围内回退到完整题库。收藏本为空时本轮不出题。错题存在但尚未到复习时间时，计时提醒可以等待到期，或由用户点「立即学习」提前练。
2. **确定学习档位。** 每个题库单独保存当前档位，初次从该范围内能取得的最低等级开始。选择全部题库时，同一轮仍可混合不同题库，候选题依据其所属题库的档位判断。同级优先选择未见过的题和更久未复习的题。没有当前级新题时，可以探测最接近的更高一级，最多一题，并用这类探测帮助处理缺档的小题库。
3. **填充本轮。** 默认三题先找一道到期复习题，再找一道当前档位新题。积压少且已有至少六道有效当前档位题、其中至少四道答对时，第三题可以是高一档的挑战题。遇到三道或更多到期题时，优先留两个位置给复习。单题轮次优先到期题。题量更大时仍只保留一个挑战位置，余位优先分给到期题和当前档位题。题池不足时按实际题量开始，同一题和同一 `conceptKey` 在一轮至多出现一次。
4. **记录作答。** 答对、答错和「不清楚」更新本题复习时间。普通填写题以明确的自评作为结果，跳过或停在待自评状态时不产生结果。点「立即学习」提前练习时，答对可计入现有错题本规则，但维持原定复习时间。
5. **调整档位。** 每完成一轮，可用当前档位的最近十道不同题的首次有效作答做一次判断。答对至少八道则升一档，五道或更少则降一档，其余保持。到期题、错题专轮、收藏本、提前练习及挑战题的结果用于单题复习，校准使用完整题库正常轮次的当前档位新题。一轮最多移动到相邻的可用档位，改档后重新累计样本，范围为 1 至 5。

首次有效作答按题目 ID 去重。挑战题答错会进入错题本。小题库的当前档位题做完时，允许抽一道更高的可用档位题用于探测，即使校准样本尚未凑足。题池里既没有到期题，也没有合适的新题时，定时提醒本轮跳过。「立即学习」可以优先练距到期时间最近的题。

## 单题复习节奏

| 作答                                                   | 下一次何时有资格进题池                     |
| ------------------------------------------------------ | ------------------------------------------ |
| 答错或「不清楚」                                       | 10 分钟后，回到复习起点                    |
| 新题首次答对，或错题到期后首次答对                     | 1 天后                                     |
| 连续在到期后答对                                       | 依次拉长到 3、7、14、30 天，之后维持 30 天 |
| 提前练习答对                                           | 保持原定时间                               |
| 跳过、稍后提醒或关闭窗口时仍未作答的题，以及待自评的题 | 保持原定时间                               |

这里的时间表示下次可抽到的时间。Pingo 仍按已有的提醒节奏和勿扰设置出题，积压的题可以分到后续轮次。错题本的「连续答对两次移出」与长期复习分开。移出错题本后，完整题库模式仍能在该题到期时再抽到它。

例如，第一天先见到 `apple` 的拼写题，点「不清楚」后看答案。下一次合适的提醒再尝试拼写，答对后安排到次日。次日再次答对便可移出错题本，随后在完整题库中进入更长的间隔。同一个词的选释义题按自己的进度复习。

## 接入现有项目

| 模块       | 接入方式                                                                                                                                                       |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 题库与导入 | 在题目和转换提示词中加入可选 `difficulty`、`conceptKey`。导入器校验后存储，编辑器可以修改。                                                                    |
| 抽题与提醒 | 保留 [现有调度器](../src/application/reminders/scheduler.ts) 的计时与题池规则。生成新会话时调用学习器，已开始的会话继续使用快照。                              |
| SQLite     | 按题 ID 保存 `step`、`dueAt`、`lastAttemptAt`。按题库保存当前档位和最近的校准样本。到期查询用索引和限量查询。                                                  |
| 作答写入   | 在 [现有答题事务](../src/infrastructure/database/reminder-store.ts) 内更新单题进度、错题本和会话。提交和自评沿用同一题只记一次的规则。升降档在完成轮次时处理。 |
| 界面       | 在现有学习提醒中提供「随机抽题」和「循序渐进」。循序渐进可显示当前档位与到期题数。                                                                             |

上线前用可控时钟验证到期、冷启动、小题库、重复提交、跨题库隔离和重启恢复。试跑时以相近练习时长与随机抽题对比，关注隔天和一周后的首次回忆正确率、完成率和「不清楚」占比。比较时使用相同难度和答题形式的测验题。
